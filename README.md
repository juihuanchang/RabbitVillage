# Rabbit Village

以 Godot 4 製作的療癒村莊生活遊戲。玩家可以陪 Amy 在家休息、前往森林或湖邊活動，並逐步建設村莊。

## 主要目錄

- `assets 美術、音效等素材(不放程式)`：背景、角色與建築圖片。
- `data`：日記故事與公告文字資料。
- `models`：存檔及各玩法使用的資料型別。
- `player`：Amy 的角色節點、移動與遊戲系統入口。
- `scenes  場景`：Godot 場景與畫面控制腳本。
- `systems`：活動、建築、日記、農田、成長、公告及存檔系統。
- `addons/godot_mcp`：開發期間使用的 Godot MCP 外掛，不屬於遊戲玩法。

## 目前內容

- Amy 的飢餓、心情與體力狀態。
- 家中、森林與湖邊活動。
- 活動倒數、離線完成、存檔與日記。
- 成長事件與成長相簿。
- 咖啡廳、小休息亭、公告欄與固定胡蘿蔔農田。
- 建築施工、放置、收回、農田生長與胡蘿蔔收成。

## 開發設定

專案使用 Godot 4.6，主要場景為 `scenes  場景/home/HomePage.tscn`。
